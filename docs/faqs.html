Frequently asked questions

Practical answers for setup, input files, and genotype interpretation.

Where is ./input?

It is the input folder inside your current working directory. After cd ~/genoflu_asia_analysis, it means ~/genoflu_asia_analysis/input. This analysis folder is separate from the GenoFLU-Asia program folder. Use pwd to check your location.

Do I need a separate help file?

No. genoflu-asia --help is an option built into the command and prints usage instructions without running an analysis.

Why is the command not found?

Activate the genoflu-asia Conda environment. If the command has not been registered, run bash install_command.sh from the project folder.

Why are no FASTA files processed?

Check the input folder and file extensions. The batch command reads lowercase .fasta files directly inside the folder; it does not search subfolders or read raw FASTQ files.

Does minor mean a low-confidence assignment?

No. Minor genotypes are defined entries represented by fewer than three viruses in the study dataset. The label does not indicate a failed analysis.

Does an unassigned result mean a new genotype?

Not by itself. Check segment completeness, FASTA IDs, sequence quality, reference identities, and the current genotype key.

Why do results include earlier samples?

Each run creates a new timestamped workbook and never appends to an earlier workbook. All .fasta files still in input are analyzed again, so move out files you no longer want to analyze. Reuse the same input and output folders; existing Excel files are preserved.

Can I upload sequences to this website?

This website provides documentation and study figures. Run GenoFLU-Asia locally using the Installation and Usage instructions.

Missing or invalid input

Empty or malformed FASTA files stop the whole batch before BLAST and identify the offending file. No new workbook is saved. A valid virus with no reference alignments remains in the workbook as Not assigned: No BLAST hits. Check the per-file input virus and output row counts printed in the terminal.
